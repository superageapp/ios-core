# Security Policy

Do not report security issues in public GitHub issues.

Use GitHub private vulnerability reporting when enabled. If private reporting is
not available, contact the maintainer through the email shown in the repository's
commit metadata and include `SECURITY` in the subject.

SuperAgeCore does not collect, transmit, or persist health data. Security reports should focus on package integrity, unsafe code behavior, supply-chain configuration, and unsafe integration documentation.

Please include a clear description, affected versions or commits, reproduction steps when available, and the expected security impact. Do not include personal health data in reports.
