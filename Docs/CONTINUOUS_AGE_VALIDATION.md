# Continuous-age validation for 0.5.0

Algorithm RFC: https://github.com/superageapp/ios-core/issues/7

## Correctness

The existing integer algorithm's source/tests at the app-pinned revision
`e1fec4603e67e63532c2c880105f68353b8fad84` match the pre-change checkout. The new
continuous-age fixture anchors were generated by independently compiling those
pinned sources; expected fractional values were blended outside the new Swift
implementation. Existing golden fixtures remain unchanged.

The added suite checks:

- Exact full-result equality at 26 integer anchors, including all mapping modes.
- Thirteen fractional golden results: male/female references, integer-band
  boundaries, mapping caps, custom mapping, sparse observations, disabled
  metrics, excluded domains, assisted mobility, empty data and a focus-confidence
  modifier transition from 0.72 to 0.756.
- Continuity on both sides of 432 birthday points: every age 19 through 90,
  both sex references and all three mapping modes. Fitness Age, domain scores,
  confidence and instrument counts are covered.
- Integer JSON compatibility, precise fractional JSON round trips, safe invalid
  age handling, adult eligibility, exact observed values and relative-standing
  recomputation at a clamp boundary.

Run the package checks:

```sh
swift build
swift test
swift build -c release
swift test -c release
```

## Performance

The reproducible benchmark measures only the pure core calculation. It excludes
JSON decoding, HealthKit queries, sampling windows and date-of-birth/calendar
work. It warms the calculator, measures 10,000 fractional calculations using the
13 fixture inputs and keeps a checksum to ensure the results are consumed.

```sh
swiftc -O $(find Sources -name '*.swift') Scripts/benchmark-continuous-age.swift -o /tmp/superage-continuous-age-benchmark
/tmp/superage-continuous-age-benchmark Tests/SuperAgeCoreTests/Fixtures/fitness_age_continuous_golden.json
```

Measured on 2026-10-05, Mac13,1, macOS 26.6.2, Apple Swift 6.4:

| Measurement | Milliseconds |
| --- | ---: |
| Median | 0.017500 |
| 95th percentile | 0.022167 |
| Maximum observed | 0.133583 |
| Target | <10 |

Checksum: `1349835.4212105055`. This is local optimized macOS performance;
physical iPhone/Watch timing belongs to the host app validation.
